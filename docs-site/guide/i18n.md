# 多語言

管理端內置**三種語言**，基於 vue-i18n 實現，默認**簡體中文**。

| 語言 | 標識 | 簡稱 |
|---|---|---|
| 简体中文 | `zh-CN` | 简（默認） |
| 繁體中文 | `zh-TW` | 繁 |
| English | `en` | EN |

## 切換入口

點擊**頂欄右側的語言下拉**（`LangSwitch` 組件）即可切換，選擇持久化到 `localStorage`（鍵名 `nova_lang`），刷新不丟。

## 深鏈接

支持 URL 查詢參數直達語言，與主題的深鏈接方式一致：

```text
http://localhost:5173/?lang=zh-TW
http://localhost:5173/?lang=en
```

`?lang=` 的優先級高於 `localStorage`，且會把該語言寫回本地持久化；非法值回退默認簡體中文。

## 文案組織

語言包位於 `web/apps/admin/src/locales/`，按頁面模塊拆分：

- `index.ts`：創建 i18n 實例、定義語言列表與讀取優先級（`?lang=` → `localStorage` → 默認 `zh-CN`），把各模塊片段按**頂層命名空間 = 頁面名**合併；
- `modules/base.ts`：外殼文案（`common` / `login` / `layout` / `dashboard` / `http` / `router`）；
- `modules/user.ts`、`modules/role.ts` 等：各頁面片段，每個片段導出 `{ zhCN, zhTW, en }` 三份。

新增一個頁面的文案：

1. 在 `modules/` 下新建 `<page>.ts`，導出 `zhCN` / `zhTW` / `en` 三份對象；
2. 在 `index.ts` 中 import 並登記到 `pageFragments`。

模板中即可以 `$t('user.xxx')` 使用（頂層鍵即頁面名）。
